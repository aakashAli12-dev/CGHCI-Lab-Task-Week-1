## Lab Tasks

This repository contains my Computer Vision laboratory tasks and practical exercises completed as part of the Computer Vision course.

The tasks focus on basic image processing and fundamental concepts used in Computer Vision.

## Week 1

### Topics Covered

* Pixel
* Image Resolution
* PPI (Pixels Per Inch)
* Aspect Ratio
* Frame Buffer
* Color Depth (Bit Depth)
* Monochrome
* Frame Rate (FPS)
* Raster vs. Vector Graphics
* Image Compression

### Practical Programs

The following Python programs demonstrate basic image processing concepts:

* **Pixel** — Accessing and displaying the RGB value of a specific pixel.
* **Image Resolution** — Finding the width, height, and resolution of an image.
* **Image Compression** — Compressing an image by reducing its JPEG quality and saving the compressed image.

## Technologies Used

* Python
* Pillow (PIL)
* OpenCV
* NumPy
* VS Code

## Installation

Install the required Python library using:

```bash
pip install pillow
```

If OpenCV and NumPy are used in the project, install them using:

```bash
pip install opencv-python numpy
```

## How to Run

1. Open the project folder in VS Code.
2. Make sure Python is installed.
3. Place the required image inside the project folder.
4. Install the required libraries.
5. Run any Python program using:

```bash
python pixel.py
```

or

```bash
python resolution.py
```

or

```bash
python compression.py
```
